# Sept-CICD
This repository we are including Terraform, Docker, K8s and CICD using Github Action (Which includes the Sonarqube and Trivy Scanner)

# Terraform Installation URL:
https://developer.hashicorp.com/terraform/install

# Terraform Registry URL
https://registry.terraform.io/providers/hashicorp/aws/latest/docs/resources/instance

# Setup Amazon CLI
https://docs.aws.amazon.com/streams/latest/dev/setup-awscli.html
Iam User should be created and configured using cli


# Terraform commands
terraform init => This command use for intialising the plugins and providers

terraform fmt => format the terraform files

terraform validate => validating the terraform files

terraform plan => planning the terraform resources and work like the blueprint of the resources

terraform apply => to execute the terraform resources and also adding the "yes" to be proceed it

terraform destroy => to destroy the terraform resources.
